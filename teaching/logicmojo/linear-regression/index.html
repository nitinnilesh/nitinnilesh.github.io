Suggested order for two classes

Class Math focus Student outcome
Class 1 Line equation, slope/intercept, residuals, RSS, MSE, OLS intuition, gradient descent intuition. They can explain what the line means and why one line is better than another.
Class 2 Metrics, R2, multiple regression equation, coefficient interpretation, assumptions, multicollinearity, polynomial idea. They can build and judge a regression model like a practical ML workflow.
