Last updated: October 9, 2026.

This website publishes educational and professional material. It does not sell personal information or use visitor data for personalized advertising.

## Optional analytics

The ML Interview Preparation material may use Google Analytics after a visitor chooses **Allow analytics**. Analytics helps identify which lessons are useful, how readers navigate the course, and where the material can be improved. The implementation disables Google signals and advertising-personalization signals.

Visitors can decline analytics without losing access to any course content. The choice is stored in the browser's local storage.

## Questions and comments

The ML Interview Preparation discussion is provided by [Giscus](https://giscus.app/) and GitHub Discussions. Loading or using the discussion may send technical request information to Giscus and GitHub. Posting requires a GitHub account, and comments are public under the website repository's Discussions section. GitHub's own privacy terms apply to that activity.

## Hosting

The website is hosted by GitHub Pages. As with most web hosting services, GitHub may process technical request information needed to deliver and protect the site.
